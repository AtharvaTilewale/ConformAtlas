# Brand assets

| File | Use |
|---|---|
| `conformatlas-logo.svg/.png` | Primary lock-up (icon + wordmark) on light backgrounds |
| `conformatlas-logo-white.svg/.png` | Lock-up for dark backgrounds |
| `conformatlas-banner.svg/.png`, `-white` | Lock-up with tagline (slides, documentation) |
| `conformatlas-logo-on-white.png`, `conformatlas-banner-on-white.png` | Opaque white card (no transparency) — the README header; identical on GitHub's light and dark themes |
| `conformatlas-icon.svg/.png`, `-white` | Icon only (favicon, app icon, social avatar) |

The icon is a topographic map of a two-basin free-energy landscape clipped to a disc — an *atlas* of conformational space — with the two minima marked. Colours: ink `#0F2743`, teal `#0FA3A3` (light), `#5FD1CC` (on dark). Wordmark: Noto Sans Light + SemiBold, converted to outlines so the SVGs need no fonts.

All files are generated by `make_logo.py` in this directory (`python make_logo.py`, requires matplotlib and the Noto Sans fonts); edit the script rather than the exports.

## README figure

`readme-landscape.png` is the unmodified `figures/fel_2d_3d.png` of the main run of the
[tutorial](../tutorial_adk.md) (rendered at `--fig-dpi 125`) on the adenylate kinase example data (4,187 frames, 1 µs,
Cα, 300 K):

```bash
conformatlas analyze \
    -s examples/adk/adk_ca.pdb -f examples/adk/adk_ca.xtc -n examples/adk/index.ndx \
    -l C-alpha -c C-alpha -T 300 --bins 30 --bootstrap 200 \
    --msm --msm-lags 1,2,5,10,20,50,100,200 \
    --residue-analysis --n-representatives 3 --fig-dpi 125 \
    -o tutorial/adk
```
