# Brand assets

| File | Use |
|---|---|
| `conformatlas-logo.svg/.png` | Primary lock-up (icon + wordmark) on light backgrounds |
| `conformatlas-logo-white.svg/.png` | Lock-up for dark backgrounds |
| `conformatlas-banner.svg/.png`, `-white` | Lock-up with tagline (README header, slides) |
| `conformatlas-icon.svg/.png`, `-white` | Icon only (favicon, app icon, social avatar) |

The icon is a topographic map of a two-basin free-energy landscape clipped to a disc — an *atlas* of conformational space — with the two minima marked. Colours: ink `#0F2743`, teal `#0FA3A3` (light), `#5FD1CC` (on dark). Wordmark: Noto Sans Light + SemiBold, converted to outlines so the SVGs need no fonts.

All files are generated by `make_logo.py` in this directory (`python make_logo.py`, requires matplotlib and the Noto Sans fonts); edit the script rather than the exports.
